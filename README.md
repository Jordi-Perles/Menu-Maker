# Menu-Maker
## Descripción del Proyecto
El objetivo de este proyecto es crear un algoritmo que distribuya 
una serie de recetas de manera aleatoria con el fin de generar
un menú semanal para el usuario.

## Funcionamiento
El algoritmo pedirá un archivo txt con el nombre de las recetas que quiera
el usuario, posteriormente, elegirá el número de días en los que quiere repartir
las recetas. A continuación, se ejecutará el algoritmo y se generará un txt con el resultado.

Se contemplan dos modalidades:
- Planificación de lunes a viernes (5)
- Planificación de lunes a domingo (7)
