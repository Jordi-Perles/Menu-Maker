# MENU-MAKER

## Descripción
Generador automático de menús semanales mediante la distribución aleatoria de recetas.

## Funcionalidades
- Generación aleatoria de menús.
- Selección de planificación de lunes a viernes o de lunes a domingo.
- Exportación del menú generado a un archivo TXT.

## Tecnologías 
- Python

## Instalación y Ejecución
1. Clona el repositorio en el directorio deseado.
2. Crea un archivo llamado recetas.txt en el directorio raíz del proyecto.
3. Añade el título de cada receta en una línea diferente.
4. Abre un terminal en el directorio src.
5. Ejecuta el programa: python algorithm.py
